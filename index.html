Это официальный сайт «Нашей Марки»?

Нет. Это независимый демонстрационный проект для презентации дизайна и возможностей будущего сайта. Название используется, чтобы показать предполагаемому заказчику концепцию.

Есть ли доставка?

Информация о подключении сети к доставке пока не подтверждена. Если компания использует Яндекс Еду или другой сервис, на официальный сайт можно добавить прямой переход к заказу. Эта демонстрационная версия не принимает заказы.

Можно ли посмотреть реальные цены и меню?

Пока нет. Для публикации проверенного меню нужны сведения от компании. Придуманных цен и состава блюд здесь нет.

Как найти ближайшую точку?

В блоке адресов есть работающий поиск по двум демонстрационным записям. Полный список магазинов добавляется после подтверждения компанией.

Этот сайт можно перенести на другой хостинг?

Да. Это обычные файлы HTML, CSS, JavaScript и SVG. Сейчас подключены внешние демонстрационные фотографии: для полностью автономного сайта их нужно сохранить локально либо заменить собственными.
