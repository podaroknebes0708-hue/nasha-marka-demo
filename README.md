# «Наша Марка» — презентационный сайт (концепт)

Неофициальная демонстрационная версия для предложения владельцу сети в Новосибирске. Проект не является действующим сайтом компании.

## Состав
- `index.html`: адаптивный сайт на HTML, CSS и JavaScript без конструкторов.
- Первый экран: утверждённая иллюстративная фотография шаурмы, созданная ИИ; встроена в HTML в WebP, поэтому не зависит от внешнего фотохостинга.
- Разделы: ассортимент (демонстрационный), поиск магазинов (неполные сведения), презентация возможности доставки, FAQ.
- Мобильное меню и навигация по секциям.

## Важно перед показом владельцу
- Цена, состав меню, фотографии компании, часы работы, полный список точек и наличие доставки не подтверждены владельцем.
- Сайт не принимает оплату, заявки и заказы.
- Другие иллюстративные фотографии могут загружаться со сторонних ресурсов, и для запуска должны быть заменены материалами с проверенными правами.
- Фирменное название и материалы компании использовать коммерчески только с согласованием.

## Размещение
Статический сайт из `main` → `/(root)` на GitHub Pages. Исходный код можно перенести на другой хостинг. Это не сайт на Wix.
