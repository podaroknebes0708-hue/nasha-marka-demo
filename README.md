# «Наша Марка» — концепция сайта сети

Неофициальный дизайн-проект для предварительного предложения владельцу сети в Новосибирске. Не является сайтом компании и не связан с её руководством.

## Две отдельные страницы

1. [Демонстрационный сайт для покупателей](https://podaroknebes0708-hue.github.io/nasha-marka-demo/) — `index.html`. Первый экран с утверждённой фотографией, каталог категорий, демонстрационный поиск магазинов, концепция интеграции доставки.
2. [Коммерческое предложение владельцу](https://podaroknebes0708-hue.github.io/nasha-marka-demo/proposal.html) — `proposal.html`. Ценность для бизнеса, интерактивная демонстрация первого сайта, функциональные возможности, этапы согласования и передача исходников.

Обе страницы мобильные и построены на HTML, CSS и JavaScript. Они не привязаны к Wix. Ссылки GitHub Pages необходимо проверить после публикации; наличие файлов в репозитории не подтверждает доступность опубликованного сайта.

## Что ещё требует согласования с компанией

- Права на бренд, логотип и реальные фотографии.
- Подтверждённые точки сети, адреса и часы работы.
- Подробный ассортимент, состав блюд и цены.
- Доставка (Яндекс Еда или другой сервис), официальные ссылки и условия.
- Объём коммерческой разработки, сроки, бюджет, поддержка и условия договора.

В проекте не подключены оплата, приём заказов или сбор контактных данных. Изображения на первом экране являются иллюстративными, включая фото, сгенерированное ИИ. Некоторые фото каталога могут зависеть от внешнего источника; в окончательном сайте их нужно заменить лицензированными и/или материалами компании.

## Публикация и переносимость

GitHub Pages: `main` → `/(root)`. Исходники можно разместить на другом статическом хостинге, в том числе российском. Права на сторонние материалы определяются их лицензиями, а передача оригинальных исходников и договорных прав оформляется отдельно.

Последнее обновление концепции: 29 октября 2026 года.
